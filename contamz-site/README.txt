CONTAMZ — PACOTE DE PUBLICAÇÃO

CONTEÚDO
- index.html: página principal
- app.html: demonstração de registo e resumo
- styles.css: estilos responsivos para telemóvel e computador
- app.js: lógica da demonstração (dados guardados apenas no navegador)
- netlify.toml: configuração simples para publicação no Netlify

PUBLICAR GRATUITAMENTE NO NETLIFY
1. Abra https://app.netlify.com/drop num computador.
2. Extraia o ZIP para obter a pasta contamz-site.
3. Arraste a pasta contamz-site para a área de publicação do Netlify Drop.
4. Aguarde a publicação. O Netlify apresentará um endereço público terminado em netlify.app.
5. Teste o endereço e os links para index.html e app.html.
6. Para alterar o nome do endereço, abra o painel do site no Netlify e procure Site configuration / Change site name.

LIMITAÇÕES IMPORTANTES
- Este pacote é uma versão inicial publicável, não uma plataforma contabilística certificada.
- Os registos são guardados no localStorage do navegador/dispositivo; não há contas de utilizador, nuvem, sincronização nem cópias de segurança.
- O cálculo de IVA é uma simulação matemática de IVA incluído no valor bruto. Não apura IVA dedutível nem obrigações fiscais.
- Não estão implementadas partidas dobradas, plano de contas validado, balancete, demonstração de resultados ou importação de extratos.
- Antes de usar com dados reais, validar as regras e o plano de contas com contabilista habilitado em Moçambique.

CONTACTO E TEXTO INSTITUCIONAL
Foram preservados os dados de contacto e a identificação institucional constantes do material fornecido. Confirme-os antes de divulgar publicamente.
